## Project Overview

This project analyzes social media data to uncover sentiment patterns — positive, negative, and neutral — across countries, users, and platforms. It combines structured data querying, transformation, and interactive visualization to deliver actionable insights that support data-driven decision-making.

---

## Tools & Technologies

| Tool | Purpose |
|------|---------|
| Power BI | Data visualization and dashboard creation |
| SQL | Data querying and analytical processing |
| Power Query | Data cleaning and transformation |
| Excel | Initial data exploration and validation |

---

## Key Features

- **Sentiment Distribution** — Multi-dimensional breakdown of positive, negative, and neutral sentiment
- **Country-wise Trends** — Comparative sentiment analysis across geographic regions
- **User Engagement Analysis** — Influence scoring using likes and retweet metrics
- **Platform Performance Insights** — Cross-platform comparison of activity and sentiment
- **Time-based Trend Analysis** — Temporal patterns for longitudinal understanding

---

## Key Insights

- Identified countries with consistently higher positive sentiment, enabling regional benchmarking
- Surfaced high-influence users by analyzing engagement metrics such as likes and retweets
- Compared social media platforms across activity volume, reach, and dominant sentiment categories

## Project Files

| File | Description |
|------|-------------|
| `sentimentdataset_clean.csv` | Cleaned and transformed dataset used for analysis |

| `Dashboard SocialMedia Sentiment Analysis..pbix` | Interactive Power BI dashboard with all visualizations |

---

## How to Use

1. Open `Dashboard SocialMedia Sentiment Analysis.pbix` in Power BI Desktop
2. Connect or load `sentimentdataset_clean.csv` if prompted
3. *(Optional)* Run `queries.sql` to validate or extend the insights
4. Interact with the dashboard slicers and filters to explore sentiment patterns

Developed as a practical implementation of end-to-end data analytics — from raw data cleaning in Power Query and Excel, through structured querying in SQL, to interactive visualization in Power BI.
